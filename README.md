# HerramientasdeGestion

## Sistema de Automatización de Reportes Nutrimentales

### Descripción
Sistema web para automatizar la generación de reportes nutrimentales a partir de archivos Excel.

### Tecnologías
- Angular
- Node.js
- PostgreSQL
- GitHub

### Objetivo
Reducir el tiempo de elaboración de reportes nutrimentales mediante la automatización del proceso.
